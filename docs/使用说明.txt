剑网三网络诊断 0.4.0
作者：兰舟少住 · 更新日期：2026-10-02

推荐顺序：先开游戏，再开本工具。

1. 打开 jx3-network-diagnostics.exe，或者先运行安装包。
2. 选择区服。可以输入旧服名搜索，列表按合服后的名称归并。
3. 选择游戏进程，核对 PID 和 EXE 路径。工具会尝试匹配区服入口；加速后地址无法匹配时，保留手动选择的区服作为参照。
4. 默认测试 10 分钟，偶发问题可选 30 分钟或自定义 1–180 分钟。
5. 点击“开始测试”，照常玩游戏；卡顿时点击“刚刚卡了”。
6. 到时或点击“结束并分析”，查看诊断报告。
7. 点击“本次报告文件夹”，打开对应测试的独立子文件夹；名称包含日期时间和区服。把需要分享的报告和日志手动发给协助排查的人。

如果先开工具、再开游戏，点击“刷新进程列表”后选择游戏即可。
游戏重启后，工具会按原 EXE 路径查找；有多个同路径候选时不自动切换。

联网程序页面：查看各程序的上传、下载、观测累计流量、连接数；展开可看完整路径和 TCP 连接。
每进程流量不可用时，可右键 EXE 选择“以管理员身份运行”。权限不足不会伪造流量数值。

报告目录中：
- 本次测试说明.txt：区服、开始时间和本次文件用途。
- 诊断报告.md：可上传或复制给 AI 的中文报告，包含基线、阈值、异常实测值及时间。
- report.html：可离线打开的中文报告。
- report.json：完整统计与分析结果。
- samples.jsonl.gz：按变化保存并压缩的原始样本和事件，通常不需要发给 AI。
- session.json：测试配置与目录来源。

注意测量口径：
- ICMP 超时不是游戏丢包率；有些目标限制回应。
- TCP 建连耗时不是游戏内延迟。第一版主要根据多目标 ICMP 波动归因。
- 加速器可能让游戏与工具探测走不同路径。
- 各网卡分别统计，代理、虚拟网卡和回环可能重复观察流量，不能直接相加。
- 游戏和已识别中转进程的 UDP 远端通过网络事件采集，事件不可用时无法关联；未采集游戏帧时间和 TCP 重传。
- 本机不能直接看到家庭其他设备占用、光猫光功率或服务器内部故障。
- 程序异常退出时保留已落盘日志，但第一版不自动重分析未完成记录。

日志只保存在本机，不记录网络正文，不会自动上传。
给豆包等聊天助手分析时，优先使用诊断报告.md。旧记录可在报告页点击“导出给 AI 的报告”生成。旧的大体积原始日志不会自动删除。
运行环境：Windows 10/11 x64、Microsoft Edge WebView2 运行时。
安装包可在需要时联网安装 WebView2，单文件 EXE 不附带运行时。

这是玩家自用诊断工具，与剑网三、金山官方无隶属关系。

0.2 新增：自动跟随游戏和本地中转连接，记录同 IP 换端口、新地址和连接表变化。报告顶部增加中文结论；地址变化可与卡顿标记对照。中转按端点关系识别，不写死加速器名称；驱动或隧道隐藏的最终游戏地址可能不可见。

版本更新：启动工具后会自动检查 GitHub Releases，也可以点击左下角“检查更新”。
发现新版后点击“下载并安装”，下载和签名校验成功后关闭工具并安装新版。
测试进行中或正在保存报告时不能安装更新。网络不可用时可稍后重试。
单文件版也支持发起更新，完成后请从开始菜单启动安装版；原有测试记录保留。
0.3.0 及更早版本没有自动更新入口，需要手动下载并运行一次新版。
