## 0.1.0 验证记录

日期：2026-10-01。环境：本机 Windows x64，已安装 WebView2。

## 已通过

- TypeScript 严格类型检查、Vite 正式构建、Rust 编译、Clippy `-D warnings`。
- 7 项 Rust 测试：内置目录的合服别名、多接入地址保留、非法目录拒绝；全程不回应不误判为游戏丢包、拒绝连接与超时分开、公共链路关联、相邻延迟差不跨越超时。
- 浏览器界面检查：实时诊断、联网程序、报告、历史、说明导航，空状态与时长输入；1360 / 1000 / 768 / 375 像素宽度，无横向页面溢出，无前端异常。
- 12 秒真实 Windows 自检：正常到时结束、手动标记、ICMP 与 TCP 实际回应、逐行 JSONL 和离线报告生成。此轮记录 574 条连接、62 个进程，末次快照显示 936 条可解析 ETW 网络事件，事件丢失与解析失败计数均为 0。
- 真实桌面 IPC 操作：读取已存在进程的完整 EXE 路径和精确创建标识，选择进程、开始采样、添加卡顿标记、查看进程详情、提前结束、查看历史报告；JSONL 可解析，报告存在，前端无异常。
- 测试实例正常关闭，关闭后未发现残留的本工具 ETW 会话。
- 正式版 EXE 构建及启动，NSIS 安装包生成。

## 测试方式与范围

桌面交互使用单独的 `scripts/tauri.test.conf.json` 调试配置，连接本工具自己的 WebView2，不复用或关闭用户浏览器。正式配置不包含调试端口。测试中关联了工具自身进程，以验证 PID、路径、FILETIME 字符串和真实 IPC；没有把它当作真实游戏卡顿样本。

正式版窗口已验证能启动并响应。安装包已经生成，未实际安装到本机。普通权限／受限制系统下的 ETW 降级路径有实现，但本机此次实测令牌能够使用 ETW，没有在第二种 Windows 权限环境重复验证。

尚需现场验证：朋友电脑的真实十分钟以上游戏过程、实际游戏 EXE 的自动候选识别、多开客户端、加速器、Wi-Fi 漫游和偶发故障。软件报告提供观测证据和排查范围，不能凭当前本机正常网络实测证明能够复现朋友的故障。
